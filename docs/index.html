⚖ Features

Everything you need. Nothing you don't.

No bloated features, no unnecessary permissions. Just secure, reliable two-factor authentication.

🛡

Hardware-Backed Keys

Secrets stored in Android Keystore with StrongBox security chip. Keys never return to app memory — computed inside secure hardware.

StrongBox
📡

Smart QR Scanner

Scans otpauth:// QR codes and automatically detects algorithm, digit count, and period. No manual configuration needed.

🔒

Biometric Lock

Fingerprint, face, or device PIN required. Auto-locks when you leave the app. Screen capture blocked at OS level.

📦

Encrypted Backup

Export to a passphrase-protected file using Argon2id key derivation and AES-256-GCM encryption. Military-grade protection.

Argon2id
📄

Printable PDF Backup

Generate a PDF with QR codes for every account. Print it, store it in a safe — the ultimate offline backup.

🔃

One-Tap Migration

Import all your accounts from Google Authenticator, Microsoft Authenticator, or Aegis. One scan, done.

⭐

Favorites & Groups

Pin frequently used accounts to the top. Organize with custom groups. Search instantly across all accounts.

🌐

Fully Offline

INTERNET permission explicitly removed from the app. No analytics, no tracking, no cloud. Air-gapped by design.

Zero Network
🇧🇷

Multilingual

English, Turkish, and Arabic with full RTL support. Every string translated, every screen localized.
