What makes Veilo different from other authenticators? Veilo'yu diğer doğrulayıcılardan farklı kılan ne?

💻

Hardware-Backed Donanım Destekli

Keys stored in StrongBox secure chip, never accessible by any app or process. Anahtarlar StrongBox güvenli çipte saklanır, hiçbir uygulama veya işlem tarafından erişilemez.

⚡

Truly Offline Tamamen Çevrimdışı

INTERNET permission completely removed. Your secrets never touch a network. INTERNET izni tamamen kaldırıldı. Sırlarınız asla bir aga dokunmaz.

💥

Memory Zeroing Bellek Sıfırlama

Secret key material is zeroed from memory immediately after use. No residual traces. Gizli anahtar materyali kullanımdan hemen sonra bellekten sıfırlanır. Kalıntı iz yok.

🔎

Open Source Açık Kaynak

Full source code on GitHub. Audit it yourself, verify every claim we make. Tam kaynak kodu GitHub'da. Kendiniz denetleyin, yaptığımız her iddiaya doğrulayın.
