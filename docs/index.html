Features

Everything you need for secure two-factor authentication

🔒

Hardware-Backed Keys

Secrets stored in Android Keystore with StrongBox security chip support. Keys never return to app memory.

📡

QR Code Scanner

Scan otpauth:// QR codes instantly. Automatic detection of algorithm, digits, and period parameters.

🔒

Biometric Lock

Fingerprint, face, or device PIN required to unlock. Auto-locks when leaving the app.

📦

Encrypted Backup

Export accounts to a passphrase-protected file (Argon2id + AES-256-GCM). Import on any device.

📄

Printable PDF

Generate a PDF with QR codes for all accounts. Print and store as a physical offline backup.

🔃

Easy Migration

Import from Google Authenticator, Microsoft Authenticator, or Aegis with one scan or file pick.

📌

Favorites & Groups

Pin frequently used accounts to the top. Organize with custom groups: Work, Personal, Finance.

🌐

Fully Offline

INTERNET permission explicitly removed. No analytics, no tracking, no third-party services. Air-gapped by design.

🇧🇷

Multilingual

Available in English, Turkish, and Arabic. RTL layout fully supported.
